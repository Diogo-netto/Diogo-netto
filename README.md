O sistema está em **uso real contínuo há mais de 9 meses**, auxiliando a equipe na organização diária dos serviços de banho e tosa.

# 🏓 ALTM Pro

## Sistema de Gestão de Torneios de Tênis de Mesa

O **ALTM Pro** é um dos projetos mais complexos que desenvolvo.

A aplicação foi criada para organização de **torneios reais de tênis de mesa**, trabalhando com regras esportivas, classificação de atletas, grupos, mata-mata e diferentes formatos de competição.

O sistema já foi utilizado em **diversos torneios reais** e continua evoluindo através de testes e utilização por organizadores.

### 👤 Gestão de Atletas

- Cadastro de atletas
- Clubes
- Cidades
- Categorias
- Ranking
- Rating
- Histórico de competições

### 🎲 Formação de Grupos

O sistema possui regras para formação e organização automática dos grupos.

Entre os critérios trabalhados estão:

- Cabeças de chave
- Ranking
- Rating
- Ordem de inscrição
- Distribuição de atletas
- Separação de atletas do mesmo clube
- Separação por cidade quando necessário

### 🧮 Classificação Automática

A aplicação calcula automaticamente:

- Vitórias
- Derrotas
- Sets
- Pontuação
- Classificação
- Critérios de desempate

### 🏆 Mata-Mata

Após a fase de grupos, o sistema consegue gerar automaticamente diferentes estruturas eliminatórias.

Entre os recursos estão:

- Mata-mata automático
- Diferentes formatos de chave
- Divisões
- Prévia das chaves
- Classificação dos atletas
- Progressão automática

### 🏓 Controle da Competição

- Controle de mesas
- Partidas em andamento
- Resultados
- Organização das rodadas
- Controle administrativo
- Acompanhamento do torneio

### 💾 Backup e Recuperação

O sistema possui mecanismos de:

- Backup
- Exportação
- Restauração
- Recuperação das informações da competição

Isso permite transportar dados entre organizações e manter maior segurança sobre os registros do torneio.

### Tecnologias

`React` `TypeScript` `Vite` `Firebase` `Firestore`
